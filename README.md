МОБИЛЬНЫЙ ПОИСК АДРЕСОВ ТОВАРОВ

Файлы: app.py, index.html, requirements.txt.

Развёртывание в Streamlit Community Cloud:
1. Загрузить эти три файла в корень GitHub-репозитория.
2. В Streamlit выбрать репозиторий, ветку main и Main file path: app.py.
3. Python: 3.12.
4. После публикации открыть ссылку на iPhone или Android. Для камеры нужен HTTPS и разрешение браузера на доступ к камере.

База товаров встроена в index.html из Excel "1 этаж адрес(1).xlsx" (2319 строк). Чтобы обновить данные, повторно сформируйте index.html из актуального Excel.

Поиск: точное совпадение ШК или SKU, затем поиск по названию/торговой марке. Все отдельные адреса по найденному SKU выводятся отдельно. Адрес формата склад.зона.аллея.модуль.полка разбирается на 5 частей.
